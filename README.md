# 🌦️ Weather Dashboard

A responsive **Weather Dashboard** built using **HTML5, CSS3, JavaScript, and the Fetch API**. The application retrieves real-time weather data, stores previously searched cities using **Session Storage** to minimize unnecessary API requests, and uses **Event Bubbling** for efficient event handling.

## 🔗 Live Demo

**Live:** https://manita-123.github.io/Weather/

**Repository:** https://github.com/Manita-123/Weather

---

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Real-time weather information
- 💧 Displays temperature, humidity, and wind speed
- 🌥️ Dynamic weather condition icons
- ⚡ Fetch API integration for real-time data
- 💾 Session Storage to cache searched city data and reduce duplicate API calls
- 🔄 Reuses cached weather data during the same browser session
- 🖱️ Event Bubbling for efficient event handling
- 🚫 Error handling for invalid city names
- 📱 Fully responsive design
